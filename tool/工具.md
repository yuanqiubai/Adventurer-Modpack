## 🛠 MCP 工具链

**工作目录**: `F:\ATcraft-Addon-164\forge\forge-src\forge\mcp\`

**环境变量**:
```powershell
$env:JAVA_HOME = 'F:\java 11'
$python = 'runtime\bin\python\python_mcp.exe'
```

| 脚本 | 功能 | 命令 |
|------|------|------|
| `recompile.py` | 编译 Minecraft + Mod 源码 | `& $python runtime\recompile.py` |
| `reobfuscate.py` | MCP 名称 → SRG 名称重混淆 | `& $python runtime\reobfuscate.py --srgnames` |
| `updatemd5.py` | 更新 MD5 校验和 | `& $python runtime\updatemd5.py -f` |
| `decompile.py` | 反编译 Minecraft jar | `& $python runtime\decompile.py` |
| `updatemcp.py` | 更新 MCP 映射表 | `& $python runtime\updatemcp.py` |

> ⚠️ **重混淆是必须的**：打包 addon 时务必从 `temp/client_reobf.jar` 提取 class，不能直接取 `bin/minecraft/`，否则运行时 `NoSuchMethodError`。
