## 2026-08-03 枪械的正确编写方式【这段日志由开发者本尊编写】
### 1. 枪械的蓄力机制是: 引擎在  shootOnce()  里读  item.use_duration  算蓄力倍率，伤害/弹速都乘它。而不是在重写整个函数，这回导致蓄力机制丢失。因此需要套用这一套公式:
```java
    int maxUseDuration = _item.getMaxItemUseDuration();
        int elapsedTicks = maxUseDuration - _itemInUseCount;
        float chargeRatio = 1.0F;
        if (this.charge_time > 1 && this.charge_stage > 0)
        {
            int chargeStage = Math.min(
                (int)Math.floor((double)elapsedTicks / (double)this.charge_time * (double)this.charge_stage),
                this.charge_stage
            );
            chargeRatio = (float)chargeStage / (float)this.charge_stage;
        }
        // 蓄力不足时不发射
        if (chargeRatio <= 0.0F)
        {
            return;
        }

        // 计算合并伤害（枪 + 弹药，从 NBT 字段读取而非硬编码）
        float basicDamage = this.basic_damage + ammo.basic_damage;
        float iceDamage   = this.ice_damage   + ammo.ice_damage;
```
### 2. 关于枪械的全自动处理: 在全自动中每次扣扳机 =  MachineGunMagazine.shoot_number × BasicAmmo.bulletNum 颗子弹。
### 3. 针对我自己自定义的子弹 cost 玩法，不建议使用if检测，来处理保护，最优的方法是让NBT标签 "onItemRightClick_Disable" 来自动检测，只要将枪械的耐久值和 onItemRightClick_Disable 的阈值合理调节，即可保护耐久。
### 4. 全自动(AUTO)和半自动的触发机制完全不同：
|            | 半自动 (SEMI)                                | 全自动 (AUTO)                             |
|------------|-----------------------------------------------|--------------------------------------------|
| 触发入口   | onPlayerStoppedUsing（松手时调用一次）        | 引擎每 tick 检查，调用私有 handleShoot()   |
| shootDelay | 影响下一次右键的间隔                           | 影响每一发之间的间隔                       |
| 你的覆写   | 接管了整个开火逻辑                             | 只在松手时触发一发，其余由引擎原逻辑处理   |


这就是之前说的 bug——"半自动不爆弹，全自动爆一坨"——的原因：
全自动流程：
  右键按住 → 引擎每 tick 调 handleShoot() (你的覆写管不到!)
           → 每 tick 打出 shoot_number×entity_num 发
           → 引擎循环叠加 → 弹幕海啸
           
  松手 → onPlayerStoppedUsing → 覆写打一发

所以如果想用全自动，需要在  onUsingTick  里也写一套开火逻辑（或者放弃覆写  onPlayerStoppedUsing ，走引擎原生的  handleShoot  路径）。不过当前  shootMode=SEMI ，暂时不用担心这个。

### 5. 引擎可覆写的方法:

| 方法                                                          | 作用                                |
|---------------------------------------------------------------|-------------------------------------|
| onPlayerStoppedUsing(stack, world, player, remainCount)       | 松右键开火                          |
| onItemRightClick(stack, world, player)                        | 右键按下（charge_time=0 时走这里）  |
| onUsingTick(stack, world, player, tick)                       | 蓄力中每 tick                       |
| getMaxItemUseDuration(stack)                                  | 覆盖最大蓄力时间                    |

| isFull3D()                                                    | 3D 渲染                             |
| onUpdate(stack, world, entity, slot, isCurrent)               | 每 tick 手持更新                    |
| hitEntity(stack, target, attacker)                            | 近战命中                            |
| addInformation(stack, player, list, advanced)                 | 物品 tooltip                        |
| updateCurrentAmmo(stack, ammoName)                            | public static，更新装填弹药         |
